# 추천 검색어 관리와 자동 무효화

## 사용

검색 웹을 실행하고 http://127.0.0.1:8090/admin 을 엽니다.
목록 검색/페이지 이동, 추천어 추가·수정·삭제를 제공합니다.
예: 일반 검색에서 '성'으로 후보를 받은 뒤, 관리 화면에서 '성수 커피'를 추가하고 다시
'성'을 입력하면 새 후보가 나타납니다. 장소 목록을 편집하는 기능은 아닙니다.
새 추천어는 기존 검색 이력의 집계 순위에 따라 최대 8개의 후보에 포함됩니다.
이미 다른 후보가 많은 짧은 접두어에서는 새 추천어가 상위 8개 밖에 있을 수 있습니다.

## 변경 흐름

```text
관리 페이지 POST/PUT/DELETE
 → 입력/중복/대상 검사
 → 이전 이름과 새 이름의 접두어 및 초성 집합 계산
 → 영향을 받는 prefix lock을 고정 순서로 획득
 → SQLite에서 추천어 변경 + prefix 버전 증가 + 이전 C 키 삭제 큐 저장
 → 커밋 완료
 → 메모리의 prefix 버전 갱신
 → 실제 C Mini Redis DEL(이전 키)
 → 관리 화면 결과 표시
```

예: 성수 카페를 연남 커피로 바꾸면 '성', '성수', '성수카', ...와 '연', '연남', ...,
각 이름의 초성 접두어에 해당하는 캐시를 정리합니다. 이름이 그대로여도 분류가 바뀌면
같은 후보 JSON의 kind가 달라지므로 관련 캐시를 지웁니다.
다른 접두어의 정상 캐시는 유지합니다. TTL은 계속 안전망으로 사용합니다.

## 동시성과 실패 처리

- 요청의 MISS→DB→SET은 기존 prefix lock 안에서 실행합니다.
- 편집은 같은 stripe들을 순서대로 잠급니다. 이전 계산이 끝나기 전에 먼저 DEL하고
  나중에 오래된 SET이 들어오는 순서가 발생하지 않도록 합니다.
- 캐시 HIT는 prefix 버전이 도중 바뀌었는지 확인하고, 바뀌었으면 새 키로 다시 조회합니다.
- DEL 실패가 DB 편집을 롤백하지는 않습니다. DB와 C 저장소를 묶은 분산 트랜잭션은 아닙니다.
- prefix 버전이 바뀌어 오래된 C 키를 더 이상 사용하지 않고, 실제 DEL은 SQLite의
  pending_cache_deletes 큐에서 다음 검색 때 재시도합니다. 실패 시 한 번에 계속 대기하지 않습니다.
- 버전과 큐는 재시작 후 다시 읽습니다. 같은 corpus 버전으로 재시작하면 관리 편집도 유지됩니다.
- 이 구조는 한 개의 검색 웹 프로세스가 편집을 담당하는 로컬 데모 범위입니다.
  여러 웹 워커/여러 관리 프로세스에서 동시에 쓰려면 버전 공유/분산 동기화를 추가해야 합니다.
- 원본 DB/관리 메타데이터의 보존은 C Mini Redis의 영속성 구현을 의미하지 않습니다.

## 접근 범위

127.0.0.1에 바인딩하며 관리 요청은 로컬 Host/동일 Origin/JSON/세션 토큰을 확인합니다.
토큰은 프로세스 메모리에만 존재하고 소스/파일에 기록하지 않습니다.
외부 공개용 로그인·권한 관리 기능은 아닙니다. 원격 운영 환경에는 별도의 인증/권한이 필요합니다.
일반 검색 화면에는 관리 UI를 섞지 않았습니다.

## 검증

```sh
python -m unittest discover -s tests -p test_admin.py -v
python -m unittest discover -s tests/integration -p test_search_cache.py -v
```

관리 테스트 10개: CRUD, 빈 결과/초성/이전·새 접두어 무효화, 관련 없는 캐시 유지,
변경과 진행 중 채우기 충돌, DEL 실패·재시작·재시도, 입력 오류, 토큰/Origin/JSON,
관리 화면/페이지 이동, 삭제한 초기 추천어가 빈 입력에서 되살아나지 않는지 검사합니다.
실제 C 서버 통합 테스트는 HTTP 관리 요청으로 변경하고 이전 C 키가 삭제되는지 확인합니다.
테스트는 임시 SQLite와 UUID namespace를 쓰므로 실행 중인 일반 웹 데이터를 편집하지 않습니다.

관리 JS 문법과 HTTP/정적 파일 전송을 확인했습니다. 브라우저 자동화 접근 제한으로
관리 화면의 시각적 검수와 실제 버튼 클릭 자동화는 완료하지 못했습니다.
