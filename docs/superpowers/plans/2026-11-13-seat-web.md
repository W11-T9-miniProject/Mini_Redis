# Seat Demonstration Implementation Plan

**Goal:** 전체 자리 배치도, 성명·번호 참여, 20초 선점·확정·취소와 관리자 시연을 제공한다.
**Architecture:** Flask의 서명된 세션과 기본 HTML/CSS/JS를 사용한다.
데이터의 권위는 C HTTP API에 두고 웹은 자리 규칙만 해석한다.
**Tech Stack:** Python Flask, qrcode, 기본 JavaScript, 기존 C HTTP 서버.

## Accepted requirements

- 개인 자리 두 개만 처음에 비어 있고 나머지는 실제 무기한 사전 배정이다.
- 제공된 전체 배치도를 표시한다. 코치님은 선택하지 않는다.
- 성명은 외자 포함, 번호 범위는 미확정이므로 추정 명단으로 막지 않는다.
- 학생 번호 기준 한 자리, 다른 참가자 간 경쟁은 C NX로 결정한다.
- 20초 임시 선점, 확정은 공통 시각까지, 사전 배정은 자동 만료하지 않는다.
- ID·상태를 포함한 비교 연산으로 오래된 화면의 취소·확정을 막는다.
- 관리자 키 인증, 만료 시각·외부 주소 설정, 임의 자리 무효화, QR 표시.
- C/웹 재시작 시 실제 배정을 유지하며 취소한 사전 배정을 되살리지 않는다.
- 학습 중심은 저장소이고 웹은 시연 도구다. 캐시·성능 비교는 다음 단계다.

## Steps

- [x] 실제 C 서버를 사용하는 웹 연동 테스트를 먼저 작성하고 미구현 실패 확인.
- [x] 좌표와 고정 배정 초기화, HTTP 저장소 클라이언트 구현.
- [x] 참여·선점·확정·취소·관리자·QR 엔드포인트 구현 및 오류 회귀 검사.
- [x] 전체 배치도와 모바일 대응 HTML/CSS/JS 구현, DOM 기반 안전한 문자열 표시.
- [x] 브라우저에서 참여·20초 카운트다운·자연 만료 및 모바일 너비 확인.
